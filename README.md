# 千牛趋势提报助手

独立的 Chromium Manifest V3 扩展，参照素材大师 v5.4.230 的趋势提报流程实现。使用浏览器中的千牛登录状态，页面脚本仅匹配千牛「商机发现」路径。

## 使用

1. 在 Chrome 或 EGO 扩展管理页，加载本项目的 `extension` 文件夹。
2. 点「趋势提报」，扩展会自动打开千牛「商机发现」并等待页面就绪。如果当前就在目标页，则直接启动。
3. 按页面当前选中的入口起跑。默认顺序是市场趋势、平台缺货下的相似款稀缺、同款稀缺。未显示的入口会跳过。
4. 相似款先按商机标题搜索店内商品。从首个成功提报的商品页提交完本页后结束该商机；如有批次限制，可在同一页拆批。每批默认最多 50 件。完整标题搜索明确无结果时，若商机标题包含可识别的服装款式词，可用该词补搜一次。补搜候选仍需符合页面提报状态、具有唯一商品 ID，且商品行包含该款式词。
5. 回执不明确时可点「继续」复查当前批次。已经点提交的商品不会因为复查再次提交。点「停止」会停止后续处理。

当前千牛店铺出现的「全网爆款」使用不同的同款商品和 SKU 报名流程。在素材大师 v5.4.230 的趋势脚本中，该名称和流程均没有对应入口。

## 市场趋势 · 全量提报

点击同名按钮，只运行「市场趋势」。如需限定类目或排序，请先在千牛市场趋势页设置并等列表刷新，再点按钮。它从当前列表页开始，翻到末页，逐个查看商机抽屉。

全量模式选用平台允许勾选且可唯一识别商品 ID 的行，无需商机标题出现在商品标题里。跳过空表、已提报和不可勾选的条目。回执不明时暂停复查。结束后汇总检查的商机、平台已受理件数、空表和识别失败情况。

## 验证范围

模拟测试覆盖三类入口、列表与抽屉分页、批次上限、相似款补搜、全量模式的空表判定，以及回执待核实时暂停复查。v0.2.4 已在女装店铺试跑至提报窗口，真实店铺的提交数量、平台受理和审核结果仍需验证。

运行模拟测试需已有 Chromium 和 Playwright Core：

```powershell
npm install --no-save --no-package-lock playwright-core
node .\tests\simulated-page.cjs
```

默认使用本机 Chrome，也可以将环境变量 `TREND_BROWSER` 设为 `msedge`。
