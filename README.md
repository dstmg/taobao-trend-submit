# 千牛趋势提报助手

给淘宝和天猫店铺用的浏览器扩展。它把千牛「商机发现」里反复打开商机、勾选商品、提交、核对回执的操作串起来。登录自己的千牛账号后即可使用。

**适合这样的场景**：做女装时，千牛可能给出「西装解构美学」「冷都女穿搭」等风格商机。商品标题未必写了风格名，但平台的提报窗口里已经列出了可勾选的商品。这时可以用「市场趋势 · 全量提报」，把这些候选按页面顺序处理。

## 两种运行方式

| 按钮 | 适合什么时候用 | 会处理什么 |
| --- | --- | --- |
| **趋势提报** | 想从当前入口开始处理常规商机 | 自动打开千牛「商机发现」。按页面显示的入口处理市场趋势、相似款稀缺和同款稀缺。相似款先按商机标题搜索店内商品，明确无结果时可用识别到的服装款式词补搜一次。 |
| **市场趋势 · 全量提报** | 店铺的市场趋势商机多，想批量处理千牛给出的候选 | 沿用当前页面选好的行业类目和排序，从当前页向后翻。只处理提报窗口里平台允许勾选、且能唯一识别商品 ID 的行。商品标题无需包含商机的风格名。 |

两种方式都能跳过空列表和不可提报的商品。回执不明确时，插件会暂停供你复查，点「继续」会核对当前批次。点「停止」可以结束后续处理。全量模式结束时会汇总已检查的商机、平台已受理件数和跳过情况。

## 安装

1. 在仓库点 **Code → Download ZIP**，或 [直接下载源码 ZIP](https://github.com/dstmg/taobao-trend-submit/archive/refs/heads/main.zip)，解压到固定位置。
2. 在 Chrome 或 EGO 打开 `chrome://extensions/`，打开「开发者模式」。
3. 点「加载未打包的扩展程序」，选择解压目录里的 **`extension`** 文件夹。正确的文件夹里可以看到 `manifest.json`。
4. 在浏览器工具栏找到紫色纸飞机图标。更新已有安装时，更新原加载目录的文件后，在扩展管理页点「重新加载」，再刷新千牛页面。

## 跑一轮试试

1. 登录需要操作的千牛店铺。想限定范围时，先进入「商品 → 商品运营 → 商机发现 → 市场趋势」，选好行业类目和排序，等列表刷新。
2. 点紫色纸飞机，再点 **「市场趋势 · 全量提报」**。请确认当前店铺与类目，因为点击后会实际提交符合页面条件的商品。
3. 在扩展里看运行日志和结束汇总。再回千牛查看对应商品是否显示「已提报」「审核中」或后续审核结果。**平台已受理和审核通过是两个状态。**

## 当前测试范围

当前版本 **v0.2.4**。模拟测试覆盖列表和抽屉分页、相似款补搜、批次上限、空表识别，以及回执不明确时的暂停和复查。女装店铺的群友试跑截图已确认能打开市场趋势的提报窗口。真实店铺的提交数量、平台受理和审核结果仍待进一步验收。

部分店铺显示的「全网爆款」使用不同的同款商品和 SKU 报名流程，当前版本的范围是**市场趋势和平台缺货**。插件独立运行，页面脚本仅匹配千牛商机发现路径。

## 本地测试

需要 Node.js 和本机 Chrome 或 Edge。

```powershell
npm install --no-save --no-package-lock playwright-core
node .\tests\simulated-page.cjs
```

默认启动本机 Chrome。用 Edge 时，先设置 `$env:TREND_BROWSER = 'msedge'`。
